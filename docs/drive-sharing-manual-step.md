# Google Drive 公開檢視設定

`AI-Learning-Portfolio` 的 Drive 根目錄目前僅限擁有者存取。

由於目前連線工具不支援個人 Gmail 的「知道連結的任何人」分享權限，請在 Google Drive 手動完成：

1. 開啟 `AI-Learning-Portfolio` 專案根目錄。
2. 選擇「共用」。
3. 將「一般存取權」設定為「知道連結的任何人」。
4. 權限設定為「檢視者」。
5. 使用無痕視窗驗證任一課程的圖卡、簡報、NotebookLM 提示語與 64 秒影片設計稿。

完成後，正式網站上的 Drive 資產入口才可供未登入訪客使用。
