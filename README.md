# AI Learning Portfolio｜AI 學習作品集

將課程作業重新設計為新手友善的教學網站，同時保留每個原始 GitHub Repository 作為程式碼、版本歷史與獨立 Demo 來源。

## 專案定位

- 個人 AI／資料科學作品集
- 新手友善教學網站
- 跨 Repository 課程整合平台
- 可逐步擴充為會員、學習進度、AI 助教與後台管理系統

## 技術方向

本專案採用 `gshan1209-cell/scrape` 的技術架構理念：

- Next.js App Router
- TypeScript
- Tailwind CSS
- Route Handlers API
- JSON chunk 分批資料來源
- Prisma + PostgreSQL 預留
- Python／Node.js 匯入與轉製腳本預留
